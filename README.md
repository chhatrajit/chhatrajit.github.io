# chhatrajit.github.io

Academic personal webpage of Dr. Thokchom Chhatrajit Singh.

## How to publish on GitHub Pages

1. Log in to GitHub.
2. Create a new public repository named:

   `chhatrajit.github.io`

3. Upload these files:
   - `index.html`
   - `style.css`

4. Go to:

   `Settings > Pages`

5. Under **Build and deployment**, select:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root

6. Save.

Your website will be available at:

`https://chhatrajit.github.io`

## How to update

Edit `index.html` for content and `style.css` for design.
